Plans, audits and status notes that the code has overtaken. Each file starts with
a note saying what replaced it. They are kept for context only: when one of them
disagrees with the current source, `README.md`, `AGENTS.md` or `CHANGELOG.md`,
the current files win. Versions and test counts in these files are from the date
each one was written; `tests/test_doc_versions.py` does not check this folder.
